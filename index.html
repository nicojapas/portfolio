Selected projects

Sequoia: AI MIDI SequencerNEW

A free VST3 plugin where you describe a melody in plain words and a fine-tuned model writes the notes, fully offline on your own CPU.

Fine-tuned Qwen3-0.6B with LoRA (Unsloth) on ~2,000 examples distilled from DeepSeek V4 Pro or generated in code and filtered by music-theory checks, then quantized to a ~400 MB GGUF. llama.cpp is linked into the C++/JUCE plugin and runs on a low-priority thread so audio is never blocked, with a GBNF grammar guaranteeing valid output. Every model is scored on a fixed 158-request eval (code checks plus a Gemini judge) before it ships.

Menger World

An infinite fractal corridor you can fly through and talk to. A voice agent reshapes the 3D scene as the conversation changes.

Raymarched in pure WebGL/GLSL with zero frontend dependencies. The agent calls a typed tool that mutates live shader state (rounding, domain warp, breathing speed, density, color). Two interchangeable backends behind one FastAPI WebSocket server: ElevenLabs Conversational AI for low-latency voice-to-voice, and a LangGraph path with Groq-hosted Llama 3, Pydantic outputs, and local Piper TTS.
